# Probable Death or Madness

A standalone band website. No hosting or domain is configured. The existing Johnny E website is separate and unchanged.

## Preview

Serve this folder with a static web server, for example `python3 -m http.server 8080`, then open http://localhost:8080. No installation or build step is needed.

## Add the demos

1. Put your final MP3 files in this folder (or an `audio/` subfolder).
2. Edit `tracks.js`: update each title, description and `src` path.
3. Real audio controls appear automatically for tracks with a source. Only one demo plays at a time. Empty sources show an honest “Coming soon” label.
4. Update the title fields when final song names are chosen.

Tracks are labelled Demo I, Demo II and Demo III until final titles are supplied. No placeholder audio or invented recordings are included.

## Contact and content

The minimal page contains the logo, demos and a contact link to typesofapes@gmail.com. No biography or recruitment copy is displayed.

## Future hosting

This is plain HTML, CSS and JavaScript, suitable for GitHub Pages or any static host. Keep GitHub Pages disabled until ready to publish. No CNAME or domain redirect is included. Set an absolute social-preview image URL after choosing the final domain.

Fonts are loaded from Google Fonts, with local fallbacks. No analytics, tracking scripts, cookies or autoplaying sound are included.
